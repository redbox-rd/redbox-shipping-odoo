Redbox Shipping Integration

RedBox offers innovative delivery service via lockers for a high-speed and low-cost shopping experience. Merchants enjoy same-day or next-day delivery within the same city and 2-3 days to other cities.

Our self-deposit service allows merchants to deposit shipments directly into lockers via API integration. Customers can receive, return, and track shipments 24/7 with over 2000 RedBox Points available.

Features

  • Create shipment from Sale Order
  • Cancel shipment automatically
  • Sync tracking number

How to use

  • 1 Install the module
  • 2 Configure API key
  • 3 Create Sale Order
